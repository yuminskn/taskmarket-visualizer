Taskmarket live market visualizer — bounty TSK-BRK611AN

Live URL: https://taskmarket-visualizer.pages.dev
Repo URL: https://github.com/yuminskn/taskmarket-visualizer

Stack: Vanilla HTML/CSS/JS (no framework, no build step). Charts are
hand-built inline SVG. Fonts self-hosted (Instrument Serif, Inter Tight,
SIL OFL). No wallet connection, no analytics, no tracking.

Endpoints used (all public, no key):
  /api/market/stats
  /api/stats/breakdowns
  /api/stats/platform-time-series (ranges 7d/30d/90d/all, bucket day)
  /api/stats/activity-heatmap (dimensions mode, hourOfWeek)
  /api/stats/activity-feed
  /api/ecosystem/snapshot (windows 7d, 30d)
  /api/tasks/stats
  /api/tasks (metadata only: id, chainId, requester, createdAt, status,
  mode, reward, expiryTime, submissionCount)

How and how often it refreshes:
  A server-side fetcher (scripts/fetch-data.mjs, Node, no dependencies)
  pulls every endpoint above for both chains (Tempo 4217, Base 8453),
  computes derived stats (distinct posters per week, concentration,
  died-task share), and writes public/data.json with a fetchedAt
  timestamp. It runs at least once an hour via a scheduled job, then the
  static site is redeployed to Cloudflare Pages. The page never calls the
  Taskmarket API from the browser (the API blocks cross-origin browser
  requests). The "data as of" time is shown in the top bar.

Deploy command (one command, from the repo root):
  ./scripts/deploy.sh
  (refreshes data, regenerates public/og.png, deploys public/ to
  Cloudflare Pages project "taskmarket-visualizer")

Views: money flow, headline numbers, trends (7d/30d/90d/all), breakdowns
by mode and status, heatmaps (mode x day, hour of week), distinct posters
per week, live activity feed, computed insights. Deep links:
?chain=tempo|base|both&range=7d|30d|90d|all&metric=...&heat=mode|how
