How this page works

Read this before you quote a number.

  • Source. All data comes from the public Taskmarket API at api.taskmarket.dev. No key, no login, no wallet.
  • Server-side fetch. The API blocks browser requests from other sites, so a server fetches the data and caches it. This page never calls the API from your browser.
  • Refresh. Data is re-fetched at least once an hour. The “data as of” time at the top is the last successful fetch.
  • Units. Reward amounts are stablecoins: OUSD on Tempo, USDC on Base. The API reports them in base units (6 decimals); this page divides by 1,000,000.
  • Scope. Some headline figures are platform-wide (the API returns the same value for both chains); per-chain figures are labelled Tempo or Base. “Listed tasks” means tasks the public task list returns; the platform total comes from /api/tasks/stats.
  • Endpoints used. /api/market/stats · /api/stats/breakdowns · /api/stats/platform-time-series · /api/stats/activity-heatmap · /api/stats/activity-feed · /api/ecosystem/snapshot · /api/tasks/stats · /api/tasks (metadata only — requester, date, status, mode, reward).
  • Privacy. No wallet connection, no analytics, no tracking. Wallet addresses are shown shortened, with no names or identities attached.
